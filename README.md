# WorkDay Assistant

WorkDay Assistant is a React and TypeScript application for calculating when a ServiceNow
technician should close the final task of the day without exceeding a maximum workday of
`07:29:45`.

## Current state

Phase 0 establishes the web application, strict TypeScript, quality tools, tests, and Capacitor
configuration. Business calculations are intentionally not implemented yet.

## Commands

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
npm run cap:sync
```

See the [`docs`](./docs) directory for project rules, status, and the implementation roadmap.
